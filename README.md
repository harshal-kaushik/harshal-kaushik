## Featured Projects

### 🤖 [Multi-PDF ChatApp AI Agent](https://github.com/harshal-kaushik/Multi-PDFs_ChatApp_AI-Agent)
> Production-grade Advanced RAG pipeline that transforms corporate PDF documents into structured PowerPoint presentations. Implements hierarchical parent-child FAISS indexing to eliminate context fragmentation, cross-encoder re-ranking for precision retrieval, and Pydantic schema validation to enforce structured LLM outputs — served via a decoupled FastAPI backend.

`Python` `LangChain` `FAISS` `FastAPI` `Gemini` `Streamlit` `Pydantic`

---

### 📈 [Walmart Sales Forecasting](https://github.com/harshal-kaushik/walmart-sales-forcasting)
> Time-series forecasting pipeline on real Walmart store data. Features temporal feature engineering — lag variables, rolling statistics, holiday indicators — trained with XGBoost and serialized for production deployment.

`Python` `XGBoost` `Pandas` `NumPy` `Jupyter`

---

### 🍽️ [Amazon Fine Food Review Analysis](https://github.com/harshal-kaushik/amazon-fine-food-review-analysis)
> End-to-end NLP classification pipeline on 420K Amazon reviews. Tackled a 5.4:1 class imbalance using `class_weight="balanced"` and decision threshold optimization — pushing minority class recall from **0.38 → 0.81** and weighted F1 from 0.88 → 0.94. Deployed as a real-time Streamlit application.

`Python` `Scikit-learn` `TF-IDF` `Logistic Regression` `Streamlit`
